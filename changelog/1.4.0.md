# 1.4.0 — 2026-10-10

Everything since 1.3.0: the coin economy, ranks and the player level, the transaction
history, new buttons on the home screen, redesigned modals, and a standard for specs.

## Added

### Economy
- **Coins.** Solving a task *again* pays `difficulty × days since the last solve`, minus a
  commission of `(10 − difficulty) × 10 %`. The first solve is free: it only starts the timer.
  Coins are paid only in STRICT mode, when the run is not slower than the reference.
- **Balance** in the task bar (next to RUN) with a coin-flight animation and a sound. A click
  opens **Adjust balance**: a positive number withdraws (never more than the balance), a negative
  number deposits (no upper limit); an optional comment is stored only when it is not empty.
- **Need meter** — a thin bar in the task list that fills over 7 days since the last solve —
  and the amount that can be earned from each task right now.
- **HARVEST button** on the home screen: `reward · coin · arrow · safe`. The number is the sum of
  rewards over the tasks that pass the hover filters (categories, difficulty, days, minimum reward);
  a click opens the most overdue task. The **safe icon** shows the balance: empty with a cobweb at 0,
  a small pile above 0, a mountain of gold above `HARVEST_RICH_BALANCE` (1000, `js/config.js`).
  Hover shows the balance, a click opens the transactions.
- The reward is also shown in the open task and in the global search results.
- **Sorting** of the task list: easiest / hardest, most / least needy, highest / lowest reward,
  highest / lowest rank. Hover the sort button for the menu.
- **Export / Import** of the local database (`gr_*` keys); the export asks whether to include the
  transaction history.
- **Console CLI**: `help`, `edit <task> lastSolved <date | now | none>`.

### Ranks and the player level
- **Task rank**: whole days accumulated between counted repeat solves (1 day → 1, a week → 7).
  Shown as signal bars + number in the task list, in search results and in the open task.
  Viewing the solution resets it.
- **Warning before a solution is shown**: the exact rank and reward that will be lost.
- **Player level** on the PROFILE button: `Σ 10 / (11 − difficulty)` over the tasks in the
  player's database (difficulty 1 → 1 point, difficulty 10 → 10 points).

### Transactions
- **Transactions modal** (the safe icon, or the history button next to PROFILE): a document with
  one chapter (tab) per day and the columns `time · task (click opens it) · task rank x → y ·
  coins +n and balance x → y · overall rank x → y`.
- Every history entry carries a before → after snapshot (balance, task rank, player level).

### Runner and specs
- **Results**: every assertion row shows the `expect(...)` argument; a click on a test or on an
  assertion opens the SPEC tab at that line and flashes it for 1 s.
- **`it.each` / `test.each`**: one result row per generated case, titled with the concrete input
  (`"abc" → false`).
- **STRICT is a verdict**: all tests green but slower than the reference by more than 10 % counts
  as a failure — fail sound, no reward, and the results area is darkened by the **TIME LIMIT
  EXCEEDED** modal (bars `ref.` / `your`, the limit line, **VIEW TESTS**).
- A run is killed after **3 s**; the STRICT benchmark takes at most 1.5 s per side.
- **`docs/SPEC_STANDARD.md`** — what a spec must look like (checklist, template, definition of done).
  Specs of ex1, ex2, ex21, ex25 and ex27 follow it.

### UI
- Icons instead of words: dice (RANDOM), safe (HARVEST), profile, transaction history; a new
  favicon (hexagon with `>_`).
- Every modal has a highlighted header with a close cross (Esc and a click outside work too).
- Search finds tasks by parts: `ex 15` finds `regex_15`.
- **Release notes**: a click on the version tag on the home screen opens a modal with
  `changelog/<version>.md` (the header is the version).

## Changed
- **ex1** removes only the whole word `cat`; **ex21** also counts one-letter words (difficulty 5 → 6);
  **ex27** rejects slower solutions through a timing test, not through hints.
- The default cursor replaces the crosshair.
- `libs.md` moved to `docs/`.

## Fixed
- Typing and `Ctrl+A` in the category search (`Shift+A`, `A` no longer triggered navigation).
- Going back from a task opened from search returns to its category.
- A failing run that is green but slow no longer plays the success sound.

## Data
- New `localStorage` keys: `gr_wallet` (balance), `gr_solved` (`"category/task"` → last solve, ms),
  `gr_rank` (`"category/task"` → accumulated days), `gr_history` (log), `gr_fontsize`.
  All of them go through Export / Import (the file format is still `version: 1`).
- History entry types: `solve`, `withdraw`, `deposit`, `rank`, and the legacy `reset`.
  Entries from before 1.4.0 are shown with what can be derived (balance before, task, amounts).
