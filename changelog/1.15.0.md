# 1.15.0 — unreleased

Work in progress: changes are collected here until the release is cut.
`APP_VERSION` is still 1.4.0 and the README table has no row for this version yet.

## Added

- The HARVEST button shows the player's **balance** right of the safe icon, yellow with a coin
  (`reward · coin · arrow · safe · balance · coin`). It is part of the safe: hover shows the balance,
  a click opens the transactions.
- **Profile modal** (the PROFILE button): a collection of the tasks. One tab per catalog
  (REGEX first, then ALGORITHM; the tab shows solved / total) and a grid of cards that follows the
  window width. A task in the player's database is a normal card: header with a symbol and the
  name (`EX_1`), the catalog sign in the middle, a footer with the current rank, successful
  runs, failed runs and the coins earned from this task. A task that was never solved is blurred
  under a padlock; the card still opens it. A line under the title shows the level and solved / total.
- A **clear button (×)** in the home search field, shown while the field has text; a click empties the
  search, brings the catalogs back and keeps the focus in the field.
- A **credit** at the bottom right of the main menu: a `</>` icon and "Developed and Maintained by
  Vodrion", styled like the FULLSCREEN / SOUND buttons (but not clickable). It is shown on the menu
  only, like the buttons at the bottom left.
- **Per-task statistics**: every finished run counts — green (and, in STRICT, not too slow) is a
  success, anything else (a failing test, a too-slow run, an error, a timeout) is a fail; payouts
  add to the coins of the task.

## Changed

- The **starry sky moves**: all stars rotate slowly around the horizon centre (the vanishing point of
  the plane) like a celestial sphere, rising on one side and setting behind the horizon on the other
  (`js/background-fx.js`, rotation speed `ROT_SPEED`, taken from the perk-tree background).
- **Modals can be dragged** by their header (`js/modal-drag.js`), anywhere, even partly out of the
  window. The position is reset to the center whenever a modal is opened or closed.
- The **safe icon** on the HARVEST button is **closed** by default (a dial on the door) and opens while the
  pointer is over it (or it has the keyboard focus): the door swings open and the contents — cobweb,
  a small pile or a mountain of gold — show.
- **Adjust balance** window: the big coin above the balance is gone; the balance reads
  `Balance: <coin> <number>`. The header keeps the gold bar.
- A click on the **safe** opens the **Adjust balance** window (before: the transactions). The
  transactions are opened by the history button next to PROFILE.
- The **search icon** (home and category search) is a drawn magnifier, 17 / 15 px, instead of the
  tiny text glyph `⌕`.
- The backdrop behind modals is only a **light dim** (no blur), so the animated plane and the
  lightning stay visible behind them.
- **Binary Search** follows the spec standard now: English header with the task, example and scope,
  numbered groups (basic, boundaries, not found, kinds of numbers, requests, generated array,
  performance), a row per value in the generated tables, the request limit `floor(log2(n)) + 1` for
  arrays of 1 … 1024 elements (every element and every gap between elements is searched), no
  request outside of the array, a timing test for STRICT. The data is deterministic (no
  `Math.random`), the whole spec runs in about 10 ms. The task title and description are in English.
  The reference solution is bare, without comments (the standard of `.sol` files).

## Fixed
- **Binary Search reference solution** did not export its function (`module.exports` was missing), so it
  failed its own spec and STRICT had nothing to compare with; the spec also imported a file that does
  not exist (`./alg1.js`; the app ignores the name, but it was wrong). Both are fixed. The old random
  array could also contain duplicates (the birthday paradox: 1000 values out of 10^6 collide in ~40 % of
  runs); the arrays are strictly increasing now.
- A **category card jittered** when the cursor was on its bottom edge: the hover lifted the whole card by
  2 px, the cursor was then outside of it, the card dropped back, got the hover again, and so on. The
  card stays in place now and only its content lifts.

- **The URL kept `?cat=regex`** after leaving a category with Esc or a click on the backdrop (only the
  BACK button cleaned it). The menu view now drops the query parameters itself, so every way back to
  the menu gives a clean URL.
- The **REGEX icon**: the caption "REGEX ENGINE" was wider than the frame and its last letters
  stuck out at the bottom right. The caption is now "REGEX" and fits inside.
- **Scrollbar** in the modals: its track is transparent now (it was a dark strip that looked like a
  notch cut out of the modal), and in the changelog and profile modals the header stays fixed while
  only the content scrolls, so the scrollbar no longer runs beside the header.
- The **player level** on the PROFILE button showed 0 after a page reload (it was calculated before
  the task list had loaded) and only became right after the next coin change. It is recalculated
  when the tasks are loaded and whenever the home screen is shown.

## Data

- New `localStorage` key `gr_stats`: `{ "category/task": { ok, fail, coins } }`. It goes through Export /
  Import. Data from before it existed is rebuilt from the history (successes and coins; failures of
  the past are unknown and start from 0).
