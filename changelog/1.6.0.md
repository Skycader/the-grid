# 1.6.0 — unreleased

Work in progress: changes after 1.5.0.

## Changed

- **Ex26 (Product Quantities)** follows the spec standard: `🎖CERTIFIED 2026-10-22`, a header with the
  task, the example and the scope (decimals without `$`, thousands separators, other currencies, numbers
  glued to letters are left open), seven numbered groups (basic, prices as a row each, quantities as a
  row each, prices and quantities together, edge cases, the regex itself, performance) and a timing
  test for STRICT; the whole spec runs in about 8 ms. The statement the player sees now says what a
  price and a quantity are (the old text said "quantifiers"), that the regex must be global and what
  `text.match` gives, and has six examples. A price never leaks even partly ("99" from `$10.99`,
  "234" from `$1234`). The reference solution is bare (the Russian comment is gone).
- **Ex15 (Valid HTML)** follows the spec standard: `🎖CERTIFIED 2026-10-22`, a header with the task, the
  example and the scope (attributes, upper case tags, spaces inside a tag, a doctype, tags inside comments
  or scripts are left open), seven numbered groups (basic, valid texts, look-alikes inside, invalid texts,
  text outside and look-alike tags — a row each —, whole pages and the answer type, performance) and a
  timing test for STRICT; 80 tests, about 8 ms. The statement the player sees says what a valid document is
  (one `<html>` pair, nothing else outside, no second tag inside), that the tags are written exactly, and
  has eleven examples. A function that returns a match instead of `true` / `false` fails one test, not all.
  The reference solution is bare (the Russian comment and the copy of the statement are gone, `trim()` was
  redundant).
- **Ex29 (Date Format DD/MM/YYYY)** follows the spec standard: `🎖CERTIFIED 2026-10-22`, a header with the
  task, the example and the scope (the length of the month and leap years, the year 0000, a date glued by
  `/` to other numbers are left open), eight numbered groups (basic, every day and every month as a row,
  years and the format as a row each, what stands around a date as a row each, several dates, edge cases and
  the answer, performance) and a timing test for STRICT; 106 tests, about 9 ms. The statement the player
  sees now says that the task is a function `f(text)` that returns an array of strings, what a correct
  date is (day 01-31, month 01-12, four digits of the year, a whole word) and that the month length is not
  checked; eight examples. A function that returns `null` instead of `[]` fails two tests, not all. The
  reference solution is bare, with non-capturing groups (the Russian comment is gone).
- **All the other regex tasks follow the spec standard** (`🎖CERTIFIED 2026-10-23`): Ex3-Ex14, Ex16-Ex19,
  Ex22-Ex24, Ex28, Ex30-Ex32. Every task has a statement that says what is meant (examples included), a
  numbered spec with rows as tables, a timing test for STRICT and a bare reference solution; each spec was
  checked against 10-20 wrong solutions. What changed in the meaning, not only in the form:
  - Ex7 replaces only the whole word `the` / `The` (it used to turn "other" into "aor");
  - Ex5 counts only names of exactly 4 letters and the whole words cat / rat, and returns 0 (it used to fail)
    when there is no owner;
  - Ex10 is a challenge now (difficulty 4 → 5): the whole words `l?l` with any one character but `o` in the
    middle (`\bl[^o]l\b`) get a CAPITAL middle letter (`lel` → `lEl`, `lol` stays), so the replacement is a
    function with a captured group; `lalel` and `slalom` are not changed;
  - Ex11, Ex12, Ex13 count the bills by the value of the amount: the cents are optional, the zeros in front
    do not matter, both borders are pinned ($100, $99.99, $9999, $10000);
  - Ex16 counts comments anywhere in the code (it used to count only the ones at the start of a line);
  - Ex19 allows exactly the printable ASCII characters from `!` to `~` (it used to reject `+ < = > ^ | ~` and
    accept non-ASCII punctuation such as the long dash);
  - Ex23 stays the light version of Ex10: an exported regex (`\bl[^o]l\b`, used as `replace(r, "l*l")`)
    instead of a function; whole words, any one character but `o` in the middle; Ex28 is a regex export now (the statement said so, the reference was a
    function) and its lookahead for the digits no longer backtracks on long texts;
  - Ex30 takes the whole run of the allowed characters as a password, and the symbols are checked inside
    the run only; Ex31's statement was translated from Russian (what stands before the `#` is not checked);
  - the references of Ex14 and Ex24 had no `module.exports` and were not runnable.
- **Currying and Errors** follow the spec standard too (`🎖CERTIFIED 2026-10-23`). Currying: the spec pointed
  to a file that does not exist (`algo4.js`) and the reference was not exported; the statement is in English
  now. Errors: the spec checks the order, the given object (it must not change) and the ban of loops.
- **The rank bar of the rank-up animation shows what was gained**: `[===+++---]` — the old progress keeps its
  colour, the gained part is gold and grows after it, the rest is empty; in a new rank the whole bar is gold.
- **The plate of the rank-up animation can be clicked**: the cursor is a pointer and a click opens the player
  profile window, the same as the profile button. The plate does not close while the cursor is on it or the
  profile window is open, and it stays at least 5 seconds after the cursor leaves it or the window is closed.
  Leaving the task (the menu, another task) closes it at once.
