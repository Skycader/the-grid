**Шкала рангов:**

| Ранг | Тип      | Характеристика                                                 |
| ---- | -------- | -------------------------------------------------------------- |
| 1    | Знания   | Литералы и базовые символы — `\d`, `\s`, `.`                   |
| 2    | Знания   | Классы символов и квантификаторы — `[a-z]`, `+`, `{2,3}`       |
| 3    | Знания   | Группы, альтернация, якоря — `^$`, `\b`, `(a\|b)`              |
| 4    | Знания   | Захват, backreference, non-greedy — `\1`, `.*?`, флаги         |
| 5    | Знания   | Lookahead/lookbehind, Unicode — `(?=...)`, `(?<=...)`, `\p{P}` |
| 6    | Жирность | Короткий но уже давит — ~до 35 символов                        |
| 7    | Жирность | Средний, разбираешь по частям — ~35–60 символов                |
| 8    | Жирность | Длинный, легко ошибиться — ~60–90 символов                     |
| 9    | Жирность | Очень длинный, пишешь итерациями — ~90–120 символов            |
| 10   | Жирность | Монстр, даже эксперт морщится — 120+ символов                  |

**Как считать итоговый ранг:**

Это не "выбери одну строку" — это **сумма двух независимых осей**, каждая от 1 до 5:

- **Знания** — берёшь номер строки (1–5) из первого блока, которая описывает самую сложную конструкцию в паттерне.
- **Жирность** — берёшь номер строки (6–10) из второго блока по длине паттерна и вычитаешь 5, чтобы привести к шкале 1–5 (6→1, 7→2, 8→3, 9→4, 10→5).
- **Итог = Знания + Жирность.**

Примеры на реальных задачах:
- `regex_12` — `\d+:\s\$\d{0,2}\.\d+`, 20 символов, групп нет → Знания 2 + Жирность 1 = **3**
- `regex_11` — `\d+:\s\$0*[1-9]\d{2,}(\.\d+)*`, 29 символов, есть группа → Знания 3 + Жирность 1 = **4**
- `regex_30` — 4× lookahead, 88 символов → Знания 5 + Жирность 4 = **9**

10 — не жёсткий потолок, а ориентир для типичной задачи. Если паттерн одновременно и продвинутый, и огромный — сумма может уйти выше, это нормально.
